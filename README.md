# NeuraChat

NeuraChat is a multi domain AI chatbot powered by Qwen 2.5 7B and Retrieval Augmented Generation RAG. It provides accurate and context aware responses for general conversation and organization specific support by retrieving information from a knowledge base and automatically updating its data when new information is available.

## Features

- AI powered chatbot using Qwen 2.5 7B
- Retrieval Augmented Generation for accurate answers
- Supports organization specific question answering
- Automatic data extraction and knowledge base updates
- Simple search for direct queries
- Deep search for complex reasoning
- Web and mobile deployment ready

## Technologies Used

- Python
- Qwen 2.5 7B
- LangChain
- HuggingFace Transformers
- FAISS
- FastAPI / Flask

## Project Goal

The goal of this project is to build an intelligent chatbot that improves communication and provides automated support for organizations through AI powered conversation and factual information retrieval.
